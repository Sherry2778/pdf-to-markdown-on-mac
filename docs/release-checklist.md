# 发布前检查

## 当前已完成

- 中文批量界面、队列状态、逐份进度、取消和重试。
- 去掉旧启动器对某台电脑固定 Python 路径的依赖。
- 自动化测试使用合成 PDF。
- 原创代码 MIT 许可和第三方依赖说明。
- 独立应用构建和第三方许可收集脚本。
- 源码忽略文件：运行环境、私人 PDF、密钥和构建产物不入库。

## 公开源码前

- 确认 GitHub 账号与仓库名。
- 审查 README 的功能与限制描述。
- 在提交记录中使用维护者自己的 Git 身份。
- 上传源码后检查远程 CI 的实际结果。

## 公开二进制 Release 前

- 从最终 ZIP 解压后测试，不仅运行源码。
- 在 Apple Silicon 上验证选择文件、批量转换、取消、重试和预览。
- 验证源码目录与开发环境不可见时，应用仍可独立运行。
- Intel 包需经过 Intel 设备或相应 runner 验证。
- 记录 macOS 版本、架构、应用版本与测试结果。
- 审核完整第三方许可和适用的源码提供要求，尤其是 Qt/PySide6。
- 提供 Qt/PySide6 对应版本的源码获取方式和重新构建说明。
- 明确应用是否通过 Developer ID 签名与 Apple 公证。
- 将二进制放入 Release 附件，不把运行环境提交进源码仓库。

远程 CI、Apple 公证、Intel 实机验证完成前，应保持对应状态为未验证。
